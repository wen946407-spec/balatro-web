# 小丑牌 Web

基于扑克牌型的单机数值小游戏，灵感来自 Balatro。在 4 次出牌机会内，累计超过 300 分即胜利。

## 玩法简介

- 从 52 张标准扑克牌中随机发 8 张手牌
- 每轮选 1–5 张组成牌型出牌，或弃牌换新牌
- 出牌机会 **4 次**，弃牌机会 **3 次**，目标分数 **300 分**
- 支持 10 种牌型：高牌 / 对子 / 两对 / 三条 / 顺子 / 同花 / 葫芦 / 四条 / 同花顺 / 皇家同花顺

得分公式：`(基础分 + 入选牌点数之和) × 倍数`

## 安装 & 运行

无需安装任何依赖，直接用浏览器打开即可：

```bash
# 方式一：直接打开文件
open index.html

# 方式二：本地服务器（推荐，避免 file:// 限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
